# PayPilotLabs Payments

Payment gateway integrations (Stripe, Razorpay, PayPal and others) used by PayPilotLabs products.

By [PayPilotLabs](https://paypilotlabs.com). Support and requests: https://paypilotlabs.com/roadmap/

## Run it

This is a companion app: it is installed alongside a PayPilotLabs product by that product's `docker/build.sh`. See the product repo's README.
